# NOIR AUTO — дизайн-спека лендинга

Статус: v1.0. Это главный артефакт для разработки. Название "NOIR AUTO" — плейсхолдер текста, не зашивать в логику компонентов (пропс `brandName`).

Стек: Next.js + TypeScript + Tailwind CSS. Все токены ниже рассчитаны на `tailwind.config.ts -> theme.extend`.

Концепция: тёмный премиальный минимализм. Чёрный — доминирующий фон, белый/почти белый — текст, и ровно два фирменных градиента ("Ignition" и "Aurora") — единственный источник цвета на сайте. Градиенты — акцент на кнопках, рамках карточек при hover, подсветке и в заголовках, а не фоновый шум. Остальная композиция — просторная, без теней-игрушек и лишних декоративных элементов.

## 1. Цветовая палитра

### 1.1 Чёрная шкала (фон/поверхности)

| Токен | Hex | Применение |
|---|---|---|
| `bg-0` | `#0A0A0B` | Базовый фон страницы (самый тёмный) |
| `bg-1` | `#111113` | Альтернативный фон секции (чтобы отделить секцию без линии-разделителя) |
| `surface-1` | `#1A1A1E` | Карточки по умолчанию (авто-карточка, FAQ-айтем, отзыв) |
| `surface-2` | `#212126` | Приподнятое/hover-состояние поверхности, инпуты |
| `border-1` | `#2B2B30` | Тонкие разделители, границы карточек в покое |
| `border-2` | `#3A3A42` | Границы в фокусе/hover (до появления градиентной рамки) |

### 1.2 Белая шкала (текст)

| Токен | Hex | Применение | Контраст на `bg-0` |
|---|---|---|---|
| `text-primary` | `#F5F5F3` | Заголовки, основной текст | ≈ 18.2:1 |
| `text-secondary` | `#B4B4BA` | Подзаголовки, параграфы второго уровня | ≈ 9.4:1 |
| `text-muted` | `#8B8B93` | Подписи, мета-информация, placeholder | ≈ 5.2:1 |

Все три прошли WCAG AA (минимум 4.5:1 для обычного текста, у нас запас по каждому). `text-muted` — нижняя граница, не делать текст темнее на чёрном фоне.

### 1.3 Фирменные градиенты (ровно два, больше не добавлять)

**Gradient "Ignition"** — основной, для всех CTA-кнопок, активного таба, фокус-рамки инпутов, прогресс-бара калькулятора.
```
background: linear-gradient(135deg, #6C5CE7 0%, #0E7C73 100%);
```
- start `#6C5CE7` (электро-виолет), end `#0E7C73` (глубокий тил/изумруд), направление 135° (сверху-слева вниз-направо).
- Текст на кнопке — `text-primary` (`#F5F5F3`) или чистый `#FFFFFF`: контраст к обоим стоп-цветам ≥ 4.8:1 — проверено, безопасно для текста поверх всего градиента, а не только по краям.
- Hover: сдвиг стопов на 10% (`background-position` при `background-size: 140% 140%`) + добавление `box-shadow: 0 0 32px rgba(108,92,231,0.35)`. Без смены hue — только более яркое "свечение".
- Active/pressed: `filter: brightness(0.9)`, свечение убрать.

**Gradient "Aurora"** — декоративный, для рамки карточки при hover, градиентного текста в заголовках (один акцентный фрагмент, не весь h1), разделителей секций, обводки активной вкладки.
```
background: linear-gradient(90deg, #6C5CE7 0%, #9B8CFF 35%, #2FD8C4 70%, #0E7C73 100%);
```
- Используется как фон 1-2px полосы (разделитель), как `border-image`/псевдоэлемент-рамка карточки, или как `background-clip: text` для 1 акцентного слова в h1/h2.
- Никогда не кладётся сплошным фоном под текстовый блок без проверки контраста — только под короткие заголовки/рамки, либо с тёмной подложкой (`rgba(10,10,11,0.7)`) поверх, если текст лежит прямо на градиенте.

Правило: на странице одновременно не должно быть больше одной крупной градиентной поверхности в зоне видимости — это акцент, не паттерн.

## 4. Композиция секций

### 4.1 Hero
Высота — не фиксируем на `100vh`, контент диктует высоту (≈ 80–90vh на десктопе за счёт паддингов). Двухколоночная сетка на desktop (`grid-cols-2`, gap 64px): слева — eyebrow-лейбл (`caption`, uppercase, "ЭЛЕКТРО · ГИБРИД · БЕНЗИН"), h1 в 2 строки с одним акцентным словом в `gradient-aurora` text-clip, подзаголовок (`body-lg`, `text-secondary`, до 60 символов в строке), CTA-кнопка "Оставить заявку" (gradient-ignition) + вторичная текстовая ссылка "Смотреть каталог" со стрелкой. Справа — визуальная зона: место под фото авто на прозрачном/edge-fade чёрном подиуме, за машиной — мягкое радиальное свечение `gradient-aurora` с большим blur (120px), как единственный "декоративный" градиент на экране. На мобильном — одна колонка, визуал сверху (меньшей высоты, 50vw), текст и CTA под ним, кнопка full-width.

### 4.2 Каталог автомобилей
Заголовок секции + подзаголовок слева, табы-фильтр "Гибрид / Бензин / Электро" (+ "Все") справа или под заголовком. Сетка карточек: `grid-cols-3` desktop (gap 24px), `grid-cols-2` tablet, `grid-cols-1` mobile. Карточка: фото 4:3 сверху (rounded-lg, подложка `surface-1`), под фото — название модели (`h4`), строка характеристик в 2-3 чипа (`caption` + `data` для чисел: тип двигателя, разгон 0-100 или расход, цена крупно `data`/`h4`-размером), внизу — кнопка "Подробнее" (ghost, контурная) и "Оставить заявку" (маленькая gradient-ignition) рядом. Табы фильтруют карточки без перезагрузки (client-side), активный таб — подчёркивание `gradient-aurora` 2px + текст `text-primary`, неактивный — `text-muted`.

### 4.3 О салоне / преимущества
Полоса из 4 пунктов: `grid-cols-4` desktop, `grid-cols-2` tablet, `grid-cols-1` mobile. Каждый пункт — минималистичная "карточка без карточки": иконка (line-style, 32px, обводка `gradient-ignition` через `stroke` SVG или просто `text-primary`), заголовок `h4`, короткое описание `body` `text-secondary`. Разделители между пунктами — вертикальная линия `border-1` на десктопе (не рамка вокруг каждого). Пункты: "Гарантия до 5 лет", "Сертифицированный сервис", "Trade-in за 1 день", "Кредит от 3.9%".

### 4.4 Отзывы клиентов
Горизонтальная карусель (drag/scroll-snap, без сторонних каруселей — чистый CSS `scroll-snap-type: x mandatory` + стрелки), 1.2 карточки видно на мобильном (намёк на скролл), 3 на десктопе. Карточка отзыва: `surface-1`, radius `lg`, внутри — рейтинг (5 звёзд, активные — `gradient-ignition` fill через SVG, неактивные — `border-2`), текст отзыва `body`, внизу имя (`h4` размер меньше, `text-primary`) + подпись "модель: ..." (`caption`, `text-muted`). Без фото людей (плейсхолдер — инициалы в круге с `gradient-aurora` фоном).

### 4.5 FAQ
Одна колонка, max-width 760px, по центру. Аккордеон: 5-6 строк-вопросов. Закрытый айтем — строка `border-bottom: 1px solid border-1`, вопрос `h4` + иконка `+` справа. Открытый — иконка превращается в `–` (поворот 45°→90° transition), ответ `body` `text-secondary` раскрывается через `height: auto` (CSS grid-rows трюк или `max-height` transition 200ms ease). Открытый айтем получает тонкую левую полосу 2px `gradient-ignition`. Только один открыт одновременно (опционально).

### 4.6 Калькулятор кредита / trade-in
Двухколоночный блок на desktop: слева — форма (слайдеры + инпуты: "Стоимость авто", "Первый взнос" — слайдер + число, "Срок" — таб-переключатель 12/24/36/48/60 мес.), справа — карточка результата на `surface-2` с крупным числом ежемесячного платежа (`data`, размер ~`h2`, обведено `gradient-aurora` тонкой рамкой 1px), под ним мелкая разбивка (сумма кредита, переплата) `caption`. На мобильном — форма сверху, результат снизу, "прилипает" (sticky) не обязательно. Слайдер трека — `border-1` фон, заполненная часть — `gradient-ignition`, ручка — белый круг с тонкой тёмной обводкой.

### 4.7 Контакты / форма заявки
Двухколоночный блок: слева — форма (Имя, Телефон, select "Тип авто" — Гибрид/Бензин/Электро, кнопка "Отправить заявку" gradient-ignition full-width на мобильном), справа — блок контактов на `surface-1`: телефон крупным `data`-шрифтом, адрес `body`, иконки соцсетей (круглые, `border-1`, при hover — заливка `gradient-ignition`), встроенная "карта"-плейсхолдер (просто затемнённый блок с меткой, без реального iframe на этапе дизайна). На мобильном — форма сверху, контакты снизу.

## 5. Интерактивные компоненты — спецификация состояний

### Карточка авто
- Покой: `bg: surface-1`, `border: 1px solid border-1`, `radius: lg`, `shadow: sm`.
- Hover: подъём `translateY(-4px)`, граница заменяется на 1px градиентную рамку (`gradient-aurora`, реализуется через `padding: 1px` wrapper + внутренний `surface-1` div, либо `border-image`), `shadow: glow-violet`, фото чуть увеличивается (`scale(1.03)`, `transition 300ms ease`, `overflow: hidden` на контейнере фото). Цена при hover переключается в `gradient-ignition` text-clip.
- Focus (клавиатура): `outline: 2px solid #9B8CFF`, `outline-offset: 2px`.
- Transition: `all 250ms cubic-bezier(0.4,0,0.2,1)`.

### Табы фильтра каталога
- Контейнер: ряд текстовых кнопок, разделённых gap 32px, нижняя общая линия `border-1`.
- Активный: текст `text-primary`, под ним полоса 2px `gradient-ignition` (`transform: scaleX` анимация перехода между табами 200ms при смене).
- Неактивный: текст `text-muted`, hover — `text-secondary` + полоса `border-2` 1px (без цвета, просто намёк).

### Кнопка с градиентом (primary CTA)
- Покой: `background: gradient-ignition`, `color: #FFFFFF`, `radius: pill`, `padding: 14px 28px`, `font: Inter 600`.
- Hover: `box-shadow: glow-violet`, лёгкое увеличение фона (`background-size: 140% 140%` + смещение `background-position: 100% 0`), `transition: 300ms ease`.
- Active: `filter: brightness(0.88)`, без тени.
- Disabled: `background: surface-2`, `color: text-muted`, без градиента и тени.
- Secondary/ghost кнопка: прозрачный фон, `border: 1px solid border-2`, текст `text-primary`; hover — граница становится `gradient-aurora` (через wrapper-трюк), фон не меняется.

### Аккордеон FAQ
Описан в 4.5. Доп: иконка `+/–` — `stroke: text-primary`, вращение 45° при открытии через `transform: rotate(45deg)`, 200ms.

### Карусель отзывов
`scroll-snap`, стрелки-кнопки круглые 40px, `surface-2` фон, при hover — заливка `gradient-ignition`, иконка стрелки белая. Индикатор прогресса (точки) под каруселью — активная точка растягивается в полосу 20px с `gradient-ignition`.

### Поля формы (инпуты/селекты)
- Покой: `background: surface-1`, `border: 1px solid border-1`, `radius: md`, `padding: 12px 16px`, текст `text-primary`, placeholder `text-muted`.
- Focus: `border-color: transparent`, добавляется `box-shadow: 0 0 0 2px #0A0A0B, 0 0 0 4px rgba(108,92,231,0.6)` (эффект градиентного кольца через двойную тень, т.к. анимировать border-gradient дороже) — альтернатива: 1px wrapper с `gradient-ignition` фоном, внутри инпут `surface-1`.
- Ошибка: `border-color: #E5484D` (единственный служебный цвет вне палитры — только для ошибок валидации форм, не использовать decorative).
- Успешная отправка: краткий инлайн-месседж с галочкой, текст `text-primary`, фон `surface-2`, левая полоса 2px `gradient-ignition`.

## 6. Общие правила доступности

- Никогда не размещать `text-secondary`/`text-muted` на поверхности `surface-2` без повторной проверки контраста — пересчитать, если фон светлее `bg-0`.
- Градиент "Aurora" как text-clip — только на коротких акцентных фрагментах (1-3 слова), не на абзацах.
- Фокус-состояние всегда видимо (`outline` или кольцо), не убирать `outline: none` без замены.
- `prefers-reduced-motion: reduce` — отключить `translateY`/`scale` transitions на карточках и каруселях, оставить только мгновенные смены состояний.
